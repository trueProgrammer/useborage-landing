Design versus production

Know which project
you are actually buying.

Separating concept design from artwork production makes the scope more accurate and the professional fit easier to confirm.

Concept design

When the packaging look is unresolved

If the structure, identity, hierarchy, illustration, visual language, or front-of-pack direction still needs invention, start with packaging and label design. That work includes broader creative exploration and direction decisions.

Artwork production

When the system is already approved

If the visual system exists and the need is accurate adaptation across dielines, sizes, products, or markets, packaging artwork production is the clearer service. The work is still skilled, but the objective is controlled application and handoff.

Combined project

When one outcome requires both

A project can include a representative design direction followed by artwork expansion. The offer should identify the approval gate between them so a change to the creative concept does not silently propagate across every variant.

Artwork questions

Before files
go to print.

01Does Borage write or approve regulatory copy?

Not by default. You supply approved content and remain responsible for legal and regulatory sign-off. Qualified review can only be included when explicitly scoped.

02Can you work with printer-supplied dielines?

Yes. Supply the latest dielines and written printer specifications. Structural engineering or confirmation of physical pack performance is separate unless expressly included.

03Can one project cover many SKUs?

Yes. The offer should use a clear matrix of shared and changing elements so the quantity, review load, and output set are unambiguous.

04Does preflight replace a printer proof?

No. Digital preflight checks the agreed file conditions. The printer remains responsible for its production process, and the client should complete any required physical, color, barcode, or press proof approval.
