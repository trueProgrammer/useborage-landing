Animation questions

Before anything
starts moving.

01Do I need a finished script or storyboard?

No. Script, message development, and storyboard creation can be included. The offer should state which source material you supply and which planning outputs Borage manages.

02Can one project include social cutdowns?

Yes. Each duration, aspect ratio, crop behavior, content change, resolution, and codec should appear in the output matrix before production.

03Are music, voiceover, and sound design included?

Only when listed. Licensing, recording, talent usage, music, sound design, mix, captions, and localization are separate production components that should be scoped explicitly.

04Will I receive the 3D project files?

Only if named as a deliverable with compatible software and transfer terms. Final videos do not automatically include every scene, simulation cache, plugin, texture, font, or licensed asset.
